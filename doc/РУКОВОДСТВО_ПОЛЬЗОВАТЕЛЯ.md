## Введение

**SDM4055A-SC Multimeter Controller** — это современное приложение с графическим интерфейсом для контроля цифрового мультиметра Siglent SDM4055A-SC через USB с использованием протокола VISA.

### Основные возможности:

- ✅ **Одновременное измерение до 16 каналов** с автоматическим переключением
- ✅ **Поддержка различных типов измерений**: напряжение (DC/AC), ток (DC/AC), сопротивление, емкость, частота, температура
- ✅ **Настройка пороговых значений** для каждого канала с цветовой индикацией
- ✅ **Автоматическое создание отчетов** в формате CSV
- ✅ **Экспорт в Excel** с условным форматированием (зеленый/красный)
- ✅ **Загрузка конфигураций** из CSV-файлов для быстрой настройки
- ✅ **Режим симулятора** для тестирования без оборудования
- ✅ **Темная и светлая темы** оформления
- ✅ **Просмотр логов** в реальном времени

## Системные требования

### Оборудование

- **Мультиметр**: Siglent SDM4055A-SC 5½ разрядный цифровой мультиметр
- **Кабель**: USB-кабель для подключения устройства к компьютеру
- **Карта сканирования**: CS1016 (опционально, для многоканального сканирования)

### Программное обеспечение

- **ОС**: Windows 10 или выше
- **Python**: версия 3.10 или выше
- **VISA Runtime**: NI-VISA или Keysight VISA
- **Драйверы USB**: драйверы устройства (если требуются)

При первом запуске приложения вы увидите главное окно, разделенное на несколько секций:

## Описание интерфейса

### Панель подключения устройства

![Панель подключения]

- **Connect** — подключиться к выбранному устройству
- **Disconnect** — отключиться от устройства
- **Refresh** — обновить список доступных устройств
- **Выпадающий список** — выбор устройства (включая симулятор)
- **Информация об устройстве** — производитель, модель, серийный номер
- **Статус подключения** — Connected (зеленый) / Disconnected (красный)

### Панель управления сканированием

- **Serial Number** — поле ввода серийного номера изделия
  - Формат: `PSN` + 9 цифр (например: `PSN123456789`)
  - Цвет индикации:
    - ⚪ Белый — новый номер
    - 🟢 Зеленый — номер уже есть в отчете
    - 🔴 Красный — неверный формат
- **Single Scan** — выполнить однократное сканирование всех каналов
- **Load Config** — загрузить конфигурацию каналов из CSV-файла
- **Select Report File** — выбрать существующий файл отчета
- **New Report File** — создать новый файл отчета
- **xlsx** — экспортировать отчет в Excel

### Сетка индикаторов каналов

16 индикаторов (4×4), каждый показывает:
- **Номер канала** (1-16)
- **Измеренное значение** с единицами измерения
- **Тип измерения** (DCV, ACV, OHM и т.д.)
- **Диапазон** (AUTO или фиксированный)
- **Цветовая индикация**:
  - 🟢 Зеленый — значение в пределах порогов
  - 🔴 Красный — значение вне порогов
  - ⚪ Серый — канал не настроен

Каждый индикатор является интерактивным:
- **Двойной клик** — изменить тип измерения
- **Правая кнопка мыши** — изменить диапазон измерения

### Строка состояния

- **☯️ Кнопка темы** — переключение между темной и светлой темой
- **ℹ️ Кнопка логов** — открытие окна просмотра логов
- **Статусные сообщения** — текущее состояние приложения

## Подключение к устройству

### Подключение к реальному мультиметру

1. **Подключите мультиметр** к компьютеру через USB-кабель
2. **Включите мультиметр**
3. Нажмите кнопку **Refresh** для обновления списка устройств
4. **Выберите устройство** из выпадающего списка (не SIMULATOR)
5. Нажмите кнопку **Connect**

При успешном подключении:
- Статус изменится на "Connected" (зеленый)
- Отобразится информация об устройстве
- Кнопки сканирования станут активными

### Подключение к симулятору

1. Нажмите кнопку **Refresh**
2. **Выберите "SIMULATOR"** из выпадающего списка
3. Нажмите кнопку **Connect**

Симулятор генерирует случайные значения для тестирования без реального оборудования.

## Настройка каналов

### Ручная настройка

1. **Дважды кликните** на индикаторе канала
2. **Выберите тип измерения** из выпадающего списка:
   - `VOLT:DC` — Постоянное напряжение
   - `VOLT:AC` — Переменное напряжение
   - `CURR:DC` — Постоянный ток (каналы 13-16)
   - `CURR:AC` — Переменный ток (каналы 13-16)
   - `RES` — Сопротивление 2-проводное
   - `FRES` — Сопротивление 4-проводное
   - `CAP` — Емкость
   - `FREQ` — Частота
   - `TEMP:RTD` — Температура RTD
   - `TEMP:THER` — Термопара
   - `DIOD` — Диод
   - `CONT` — Проверка целостности

3. **Правой кнопкой мыши** кликните на индикаторе для выбора диапазона:
   - `AUTO` — автоматический выбор диапазона
   - Фиксированные диапазоны (зависят от типа измерения)

### Настройка через конфигурационный файл

1. Подготовьте CSV-файл конфигурации (см. раздел [Создание конфигурационных файлов](#создание-конфигурационных-файлов))
2. Нажмите кнопку **Load Config**
3. Выберите файл конфигурации
4. Настроенные каналы подсветятся, не настроенные останутся серыми

## Выполнение измерений

### Однократное сканирование (Single Scan)

Используется для измерения всех каналов один раз и записи в отчет.

1. **Введите серийный номер** изделия в формате `PSN123456789`
2. **Выберите или создайте файл отчета** (см. раздел [Работа с отчетами](#работа-с-отчетами))
3. Нажмите кнопку **Single Scan**
4. Дождитесь завершения сканирования (индикатор прогресса)
5. Результаты автоматически сохранятся в отчет

### Непрерывное сканирование

Используется для мониторинга значений в реальном времени.

1. Подключитесь к устройству
2. Нажмите кнопку **Start Scan**
3. Значения будут обновляться каждые 500 мс
4. Нажмите **Stop Scan** для остановки

## Работа с отчетами

### Выбор существующего отчета

1. Нажмите кнопку **Select Report File**
2. Выберите существующий CSV-файл
3. Имя файла отобразится зеленым цветом
4. Кнопка экспорта в Excel станет активной

### Создание нового отчета

1. Нажмите кнопку **New Report File**
2. Выберите имя и расположение файла
3. Имя файла генерируется автоматически:
   - Если загружен конфиг: `<имя_конфига>_<YYYY-MM-DD>.csv`
   - Без конфига: `report_<YYYY-MM-DD>.csv`

### Структура отчета

Файл отчета имеет формат CSV с разделителем `;`:

```csv
QR;TEST RESULT;CH1 (12.0V);CH2 (5.0V);CH3 (3.3V);Date/Time
PSN123456789;OK;12.0123456;5.0012345;3.3012345;2026-02-02 12:34:56
PSN987654321;FAILED CH2: 4.5123456 (expected: 4.9 - 5.1);12.0123456;4.5123456;3.3012345;2026-02-02 12:35:00
```

- **QR** — серийный номер изделия
- **TEST RESULT** — результат тестирования (OK или FAILED с детализацией)
- **CH1, CH2, ...** — измеренные значения для каждого канала
- **Date/Time** — дата и время измерения

### Обновление существующего серийного номера

Если серийный номер уже существует в отчете:
- При сканировании строка будет **обновлена** новыми значениями
- Поле серийного номера подсветится **зеленым**

## Экспорт в Excel

### Условное форматирование

При экспорте в Excel применяется условное форматирование на основе пороговых значений из конфигурации:

- 🟢 **Зеленая заливка** — значение в пределах порогов

### Выполнение экспорта

1. **Загрузите конфигурацию** каналов (для пороговых значений)

3. Нажмите кнопку **xlsx**
4. Выберите имя и расположение Excel-файла
5. Дождитесь завершения экспорта

- **Жирный заголовок** с выравниванием по центру
- **Автоматическая ширина** столбцов по содержимому
- **Границы ячеек** для всех данных
- **Условное форматирование** только для настроенных каналов
- **Сохранение** всех данных из CSV-файла

## Создание конфигурационных файлов

### Формат файла

Конфигурационный файл — это CSV с разделителем-запятой:

```csv
channel,Name,measurement_type,range,lower_threshold,upper_threshold
1,12.0V,VOLT:DC,AUTO,11.5,12.5
2,5.0V,VOLT:DC,AUTO,4.9,5.1
3,3.3V,VOLT:DC,AUTO,3.25,3.35
```

### Поля конфигурации

| Поле | Описание | Обязательно |
|------|----------|-------------|
| `channel` | Номер канала (1-16) | Да |
| `Name` | Кастомное имя канала | Нет |
| `measurement_type` | Тип измерения | Да |
| `range` | Диапазон (AUTO или значение) | Нет |
| `lower_threshold` | Нижний порог | Нет |
| `upper_threshold` | Верхний порог | Нет |

### Пример конфигурации

```csv
channel,Name,measurement_type,range,lower_threshold,upper_threshold
1,12.0V,VOLT:DC,AUTO,11.5,12.5
2,5.0V,VOLT:DC,AUTO,4.9,5.1
3,3.3V,VOLT:DC,AUTO,3.25,3.35
4,1.8V,VOLT:DC,AUTO,1.75,1.85
5,GND,VOLT:DC,AUTO,-0.1,0.1
6,5VSB,VOLT:DC,AUTO,4.9,5.1
7,3VSB,VOLT:DC,AUTO,3.25,3.35
8,Battery,VOLT:DC,AUTO,3.0,3.3
9,Fan_Speed,FREQ,AUTO,1000,3000
10,Temp1,TEMP:RTD,AUTO,20,30
13,Rail1_Current,CURR:DC,2 A,0.0,1.0
14,Rail2_Current,CURR:DC,2 A,0.0,0.5
```

### Комментарии в файле

Строки, начинающиеся с `#`, игнорируются и могут использоваться для комментариев:

```csv
# Файл конфигурации для тестовой платы Boreas v2.1
# Каналы 1-8: Проверка напряжений питания
# Канал 9: Контроль скорости вентилятора
# Канал 10: Мониторинг температуры
```

## Типы измерений и диапазоны

### Напряжение постоянное (VOLT:DC)

**Поддерживаемые диапазоны:**
- `200 mV` — максимальная точность (используйте SLOW)
- `2 V` — стандартный диапазон
- `20 V` — стандартный диапазон
- `200 V` — стандартный диапазон
- `AUTO` — автоматический выбор

**Ограничения:**
- ❌ Диапазоны `1000 V` и `750 V` **НЕ поддерживаются** картой CS1016
- ✅ Максимальное напряжение: 125V AC, 110V DC

### Напряжение переменное (VOLT:AC)

**Поддерживаемые диапазоны:**
- `2 V`
- `20 V`
- `200 V`
- `AUTO`

### Ток постоянный (CURR:DC)

**Только каналы 13-16!**

**Поддерживаемые диапазоны:**
- `200 µA`
- `2 mA`
- `20 mA`
- `200 mA`
- `2 A`
- `10 A`
- `AUTO`

### Ток переменный (CURR:AC)

**Только каналы 13-16!**

**Поддерживаемые диапазоны:**
- `2 mA`
- `200 mA`
- `2 A`
- `10 A`
- `AUTO`

### Сопротивление (RES)

**Поддерживаемые диапазоны:**
- `200 Ω`
- `2 kΩ`
- `20 kΩ`
- `200 kΩ`
- `2 MΩ`
- `20 MΩ`
- `100 MΩ`
- `AUTO`

### Сопротивление 4-проводное (FRES)

**Поддерживаемые диапазоны:**
- `200 Ω`
- `2 kΩ`
- `20 kΩ`
- `200 kΩ`
- `2 MΩ`
- `AUTO`

### Емкость (CAP)

**Поддерживаемые диапазоны:**
- `2 nF`
- `20 nF`
- `200 nF`
- `2 µF`
- `20 µF`
- `200 µF`
- `2000 µF`
- `AUTO`

### Частота (FREQ)

**Поддерживаемые диапазоны:**
- `AUTO`

### Температура RTD (TEMP:RTD)

**Поддерживаемые диапазоны:**
- `PT100` (стандартный)
- `PT1000`
- `AUTO`

### Температура термопара (TEMP:THER)

**Поддерживаемые типы:**
- `K` (стандартный)
- `J`
- `T`
- `AUTO`

## Поиск и устранение неисправностей

### Устройство не найдено

**Проблема**: "No VISA resources found" или подключение не удается

**Решения**:
1. ✅ Убедитесь, что VISA runtime установлен корректно
2. ✅ Проверьте подключение USB-кабеля
3. ✅ Убедитесь, что устройство включено
4. ✅ Запустите NI MAX (для NI-VISA) для проверки обнаружения устройства
5. ✅ Попробуйте другой USB-порт
6. ✅ Перезагрузите компьютер и устройство

### Ошибки импорта модулей

**Проблема**: `ModuleNotFoundError` для PySide6, qt-material или pyvisa

**Решение**:
```bash
pip install -r requirements.txt
```

### Тема не применяется

**Проблема**: Приложение выглядит не так, как ожидалось

**Решение**:
```bash
pip install qt-material>=2.14
```

### Проблемы с опросом

**Проблема**: Измерения не обновляются или показывают ошибки

**Решения**:
1. ✅ Проверьте, что устройство все еще подключено
2. ✅ Убедитесь, что тип измерения поддерживается
3. ✅ Проверьте настройки таймаута VISA в `hardware/visa_interface.py`
4. ✅ Посмотрите логи приложения для сообщений об ошибках

### Ошибка формата серийного номера

**Проблема**: Предупреждение о неверном формате серийного номера

**Решение**:
- Используйте формат: `PSN` + ровно 9 цифр
- Пример: `PSN123456789` ✅
- Неправильно: `PSN12345678` ❌ (мало цифр)
- Неправильно: `PSN1234567890` ❌ (много цифр)
- Неправильно: `SN123456789` ❌ (неверный префикс)

### Не удается записать в отчет

**Проблема**: Ошибка при записи в файл отчета

**Решения**:
1. ✅ Убедитесь, что файл не открыт в другом приложении (Excel, текстовый редактор)
2. ✅ Проверьте права доступа к файлу и папке
3. ✅ Убедитесь, что на диске достаточно свободного места
4. ✅ Закройте и снова откройте файл отчета в приложении

### Экспорт в Excel не работает

**Проблема**: Ошибка при экспорте в Excel

**Решения**:
1. ✅ Убедитесь, что файл отчета существует и не пуст
2. ✅ Проверьте, что загружена конфигурация (для условного форматирования)
3. ✅ Убедитесь, что целевой файл не открыт в Excel
4. ✅ Проверьте наличие библиотеки openpyxl: `pip install openpyxl`

### Устройство отключается во время сканирования

**Проблема**: Сообщение "Device Disconnected" во время сканирования

**Решения**:
1. ✅ Проверьте USB-кабель (рекомендуется экранированный кабель)
2. ✅ Убедитесь в стабильном питании устройства
3. ✅ Увеличьте таймаут VISA
4. ✅ Попробуйте другой USB-порт
5. ✅ Обновите драйверы VISA и USB
