## Введение

**SDM4055A-SC Multimeter Controller** — это приложение для управления цифровым мультиметром Siglent SDM4055A через USB-интерфейс. Приложение предоставляет удобный графический интерфейс для настройки многоканального сканирования, выполнения измерений и сохранения результатов в CSV-файлы.

### Основные возможности:

- 🎯 **Подключение к мультиметру** — через USB (USBTMC)
- 🔌 **Многоканальное сканирование** — до 15 каналов с индивидуальными настройками
- 📊 **Различные типы измерений** — DC Voltage, AC Voltage, DC Current, 2-Wire Resistance, 4-Wire Resistance, Frequency, Capacitance, Continuity, Diode
- 📁 **Автоматическое сохранение** — результатов в CSV-файлы с меткой времени
- 📈 **Экспорт в Excel** — с условным форматированием для визуализации данных
- 🎨 **Темная/светлая тема** — переключение между темами оформления
- 🔧 **Режим симулятора** — для тестирования без оборудования
- 📝 **Просмотр логов** — отладка и диагностика подключений

## Системные требования

### Оборудование:
- **Компьютер** с Windows 10/11 (64-bit)
- **Мультиметр** Siglent SDM4055A (опционально — для режима симулятора не требуется)
- **USB-кабель** для подключения мультиметра

### Программное обеспечение:
- **NI-VISA** — драйвер для взаимодействия с измерительным оборудованием (требуется для подключения к реальному мультиметру)
  - Скачать можно с официального сайта National Instruments: https://www.ni.com/en-us/support/downloads/drivers/download.ni-visa.html

## Установка и запуск

### Установка из готового EXE-файла

1. **Скачайте архив** с приложением `SDM4055A_Controller_vX.X.exe`
2. **Распакуйте архив** в любую папку на вашем компьютере
3. **Запустите файл** `SDM4055A_Controller_vX.X.exe` двойным кликом

> ✅ **Готово!** Приложение готово к использованию. Дополнительная установка Python не требуется.

1. При первом запуске приложение может запросить разрешение на доступ к USB-устройствам

3. Приложение откроет главное окно и будет готово к работе

## Описание интерфейса

Главное окно приложения разделено на несколько областей:

### 1. Верхняя панель инструментов

```
┌─────────────────────────────────────────────────────────────────┐
│ 📊 SDM4055A-SC Multimeter Controller          [🌙/☀️] [📋] [❓] │
└─────────────────────────────────────────────────────────────────┘
```

**Элементы управления:**

- **🌙/☀️ Кнопка смены темы** — переключение между темной и светлой темой
- **📋 Кнопка "View Logs"** — открыть окно просмотра логов
- **❓ Кнопка "About"** — информация о версии приложения

### 2. Панель подключения (Connection Panel)

```
┌─────────────────────────────────────────────────────────────────┐
│ Device Connection                                               │
│ ├─ Device: [SDM4055A Multimeter      ▼]                        │
│ ├─ Serial: [________________]                                 │
│ └─ [🔌 Connect] [📡 Simulator] [🔄 Refresh]                   │
└─────────────────────────────────────────────────────────────────┘
```

**Поля ввода:**

- **Device** — выпадающий список доступных устройств (включая симулятор)
- **Serial** — серийный номер устройства (опционально)

**Кнопки:**

- **🔌 Connect** — подключиться к выбранному устройству
- **📡 Simulator** — запустить режим симулятора
- **🔄 Refresh** — обновить список доступных устройств

### 3. Панель управления сканированием (Scan Control Panel)

```
┌─────────────────────────────────────────────────────────────────┐
│ Scan Control                                                    │
│ ├─ Serial: [________________]                                 │
│ ├─ [🔄 Single Scan]                                            │
│ └─ Status: Ready / Scanning... / Error                         │
└─────────────────────────────────────────────────────────────────┘
```

**Поля ввода:**

- **Serial** — серийный номер изделия для отчета (формат: PSN123456789)

**Кнопки:**

- **🔄 Single Scan** — выполнить однократное сканирование всех каналов

**Статус:**

- **Ready** — готов к работе
- **Scanning...** — выполняется сканирование
- **Error** — произошла ошибка

> ⚠️ **Примечание**: В текущей версии доступно только однократное сканирование.

### 4. Панель каналов (Channels Panel)

```
┌─────────────────────────────────────────────────────────────────┐
│ Channel Measurements                                            │
│ ┌─────┬─────┬─────┬─────┐                                    │
│ │ CH1 │ CH2 │ CH3 │ CH4 │  ... (16 каналов)                  │
│ └─────┴─────┴─────┴─────┘                                    │
└─────────────────────────────────────────────────────────────────┘
```

Каждый канал отображает:
- **Номер канала** — CH 1, CH 2, CH 3, ..., CH 16
- **Тип измерения** — DC Voltage, AC Voltage, DC Current, и т.д.
- **Диапазон** — текущий диапазон измерения
- **Значение** — измеренное значение с единицей измерения
- **Статус** — OK/OVERLOAD (перегрузка)

**Взаимодействие:**

- **Одиночный клик** по типу измерения или диапазону — открыть выпадающий список и выбрать значение

### 5. Панель управления отчетами (Report File Panel)

```
┌─────────────────────────────────────────────────────────────────┐
│ Report File                                                     │
│ ├─ File: [Boreas_2v1.csv                   ] [📁 Browse]      │
│ ├─ [LOAD CONFIG] [SELECT REPORT FILE] [NEW REPORT FILE] [XLSX] │
│ └─ Status: ✓ / ✗ / hidden                                     │
└─────────────────────────────────────────────────────────────────┘
```

**Поля ввода:**

- **File** — путь к CSV-файлу отчета
- **📁 Browse** — выбрать файл через диалоговое окно

**Кнопки:**

- **LOAD CONFIG** — загрузить файл конфигурации каналов
- **SELECT REPORT FILE** — открыть существующий CSV-файл отчета
- **NEW REPORT FILE** — создать новый CSV-файл отчета
- **XLSX** — создать файл Excel на основе открытого CSV с форматированием

## Подключение к мультиметру

### Подключение по USB

1. **Подключите мультиметр** к компьютеру через USB-кабель
2. **Включите мультиметр**
3. В приложении нажмите кнопку **🔄 Refresh** для сканирования устройств
4. Выберите устройство из выпадающего списка **Device**
5. Нажмите кнопку **🔌 Connect**
6. Дождитесь сообщения об успешном подключении

> 💡 **Примечание**: Убедитесь, что NI-VISA установлен на вашем компьютере.

### Режим симулятора

Режим симулятора позволяет тестировать приложение без реального оборудования:

1. В выпадающем списке **Device** выберите `SIMULATOR - Virtual SDM4055A-SC (for testing)`
2. Нажмите кнопку **🔌 Connect**
3. Симулятор будет генерировать случайные значения для всех каналов

> 💡 **Примечание**: Режим симулятора полезен для тестирования конфигураций и отладки.

## Настройка каналов

### Добавление каналов

Приложение автоматически создает 16 каналов при запуске. Каждый канал можно настроить индивидуально.

### Удаление каналов

Каналы нельзя удалить, но их можно отключить (см. раздел "Включение/выключение канала").

### Настройка параметров канала

Для каждого канала можно настроить:

#### 1. Тип измерения (Measurement Type)

**Одиночный клик** по полю типа измерения открывает выпадающий список:

- **DC Voltage** — постоянное напряжение
- **AC Voltage** — переменное напряжение
- **DC Current** — постоянный ток
- **AC Current** — переменный ток
- **2-Wire Resistance** — сопротивление (2 провода)
- **4-Wire Resistance** — сопротивление (4 провода)
- **Frequency** — частота
- **Capacitance** — емкость
- **Continuity** — проверка целостности цепи
- **Diode** — проверка диода

#### 2. Диапазон измерения (Measurement Range)

**Одиночный клик** по полю диапазона открывает выпадающий список доступных диапазонов для выбранного типа измерения.

Доступные диапазоны зависят от типа измерения (см. раздел [Типы измерений и диапазоны](#типы-измерений-и-диапазоны)).

#### 3. Состояние канала

Каналы могут находиться в двух состояниях:

- **Настроенный (цветной)** — канал есть в конфигурационном файле, включается в отчёты
- **Ненастроенный (серый)** — канал отсутствует в конфигурационном файле, не включается в отчёты

> 💡 **Примечание**: Чтобы включить канал в отчёты, добавьте его в конфигурационный файл.

## Выполнение измерений

### Однократное сканирование (Single Scan)

1. Настройте каналы (см. раздел [Настройка каналов](#настройка-каналов))
2. Введите серийный номер изделия в поле **Serial** (формат: PSN123456789)
3. Нажмите кнопку **🔄 Single Scan**
4. Приложение выполнит одно измерение для каждого настроенного канала
5. Результаты отобразятся на панели каналов и будут сохранены в отчет

> ⚠️ **Примечание**: В текущей версии доступно только однократное сканирование.

## Работа с конфигурацией и отчетами

### Загрузка конфигурации каналов

1. Подготовьте CSV-файл конфигурации (см. раздел [Создание конфигурационных файлов](#создание-конфигурационных-файлов))
2. Нажмите кнопку **LOAD CONFIG** на панели управления
3. Выберите файл конфигурации
4. Каналы из файла станут цветными (настроенными), остальные останутся серыми

> 💡 **Примечание**: Только настроенные каналы будут включены в отчеты.

### Создание нового CSV-файла отчета

1. Нажмите кнопку **NEW REPORT FILE** на панели **Report File**
2. Выберите папку и введите имя файла (например, `report_2026-02-03.csv`)
3. Будет создан CSV-файл с заголовками для настроенных каналов

### Открытие существующего CSV-файла отчета

1. Нажмите кнопку **SELECT REPORT FILE** на панели **Report File**
2. Выберите существующий CSV-файл
3. Файл будет открыт для добавления новых измерений

> 💡 **Примечание**: После каждого сканирования данные автоматически добавляются в открытый файл.

### Формат CSV-файла

```csv
QR;TEST RESULT;CH1 (custom_name);CH2 (custom_name);...;Date/Time
PSN123456789;OK;123.456;1.234;...;2025-01-26 12:34:56
PSN987654321;FAILED CH1: 123.000 (expected: 150.000 - 200.000);125.000;1.200;...;2025-01-26 12:35:00
```

## Создание Excel-отчета

Приложение позволяет создать Excel-файл на основе CSV-отчета с условным форматированием по порогам из конфигурации.

### Выполнение экспорта

1. Откройте или создайте CSV-файл отчета через кнопки **SELECT REPORT FILE** или **NEW REPORT FILE**
2. Убедитесь, что загружен файл конфигурации (кнопка **LOAD CONFIG**)
3. Нажмите кнопку **XLSX**
4. Выберите путь для сохранения Excel-файла
5. Будет создан Excel-файл с условным форматированием

### Условное форматирование

- **🟢 Зеленая заливка** — значения в пределах нормы (в пределах порогов из конфигурации)
- **🔴 Красная заливка** — значения вне пределов нормы (за пределами порогов из конфигурации)
- **⚪ Белая заливка** — нет данных или ошибка измерения

> 💡 **Примечание**: Условное форматирование применяется только к настроенным каналам с заданными порогами в конфигурационном файле.

## Создание конфигурационных файлов

Конфигурационные файлы позволяют быстро загружать предустановленные конфигурации каналов.

### Формат конфигурационного файла

Конфигурационный файл — это CSV-файл со следующей структурой:

```csv
channel,Name,measurement_type,range,lower_threshold,upper_threshold
1,Battery Voltage,VOLT:DC,200 mV,4.8,5.2
2,Reference Voltage,VOLT:DC,2 V,1.15,1.25
3,Sensor 1,RES,AUTO,1000,10000
4,Precision Resistor,FRES,2 kOhm,1.8,2.2
5,Clock Frequency,FREQ,AUTO,58,62
```

### Поля конфигурационного файла

- **channel** — номер канала (1-16)
- **Name** — пользовательское имя канала (опционально)
- **measurement_type** — тип измерения (см. раздел [Типы измерений и диапазоны](#типы-измерений-и-диапазоны))
- **range** — диапазон измерения (или AUTO для автоматического выбора)
- **lower_threshold** — нижний порог для условного форматирования (опционально)
- **upper_threshold** — верхний порог для условного форматирования (опционально)

> 💡 **Примечание**: Только каналы, указанные в конфигурационном файле, будут включены в отчёты.

### Пример конфигурационного файла

```csv
channel,Name,measurement_type,range,lower_threshold,upper_threshold
1,Battery Voltage,VOLT:DC,200 mV,4.8,5.2
2,Power Supply,VOLT:DC,2 V,11.4,12.6
3,Thermistor,RES,AUTO,1000,10000
4,Shunt Resistor,FRES,2 kOhm,1.8,2.2
5,Grid Frequency,FREQ,AUTO,58,62
6,Filter Cap,CAP,2 uF,1.8,2.2
7,Load Current,CURR:DC,2 A,1.8,2.2
8,Mains Voltage,VOLT:AC,200 V,220,240
```

### Загрузка конфигурационного файла

1. Нажмите кнопку **Load Config** на панели **Scan Control**
2. Выберите конфигурационный файл
3. Каналы будут автоматически настроены согласно конфигурации
4. Пороги будут применены для условного форматирования в Excel

## Типы измерений и диапазоны

### DC Voltage (Постоянное напряжение)

**Диапазоны:**
- `200 mV` — 200 милливольт
- `2 V` — 2 вольта
- `20 V` — 20 вольт
- `200 V` — 200 вольт
- `AUTO` — автоматический выбор диапазона

**Единица измерения:** V (вольты)

> ⚠️ **Примечание**: Максимальное напряжение 200V для карт сканирования CS1016.

### AC Voltage (Переменное напряжение)

**Диапазоны:**
- `200 mV` — 200 милливольт
- `2 V` — 2 вольта
- `20 V` — 20 вольт
- `200 V` — 200 вольт
- `AUTO` — автоматический выбор диапазона

**Единица измерения:** V (вольты)

> ⚠️ **Примечание**: Максимальное напряжение 200V для карт сканирования CS1016.

### DC Current (Постоянный ток)

**Диапазоны:**
- `2 A` — 2 ампера (только этот диапазон поддерживается картой CS1016)

**Единица измерения:** A (амперы)

> ⚠️ **Примечание**: Карта сканирования CS1016 поддерживает только диапазон 2A для измерения тока.

### AC Current (Переменный ток)

**Диапазоны:**
- `2 A` — 2 ампера (только этот диапазон поддерживается картой CS1016)

**Единица измерения:** A (амперы)

> ⚠️ **Примечание**: Карта сканирования CS1016 поддерживает только диапазон 2A для измерения тока.

### 2-Wire Resistance (Сопротивление 2 провода)

**Диапазоны:**
- `200 Ω` — 200 ом
- `2 kΩ` — 2 килоома
- `20 kΩ` — 20 килоом
- `200 kΩ` — 200 килоом
- `2 MΩ` — 2 мегаома
- `10 MΩ` — 10 мегаом
- `100 MΩ` — 100 мегаом
- `AUTO` — автоматический выбор диапазона

**Единица измерения:** Ω (омы)

### 4-Wire Resistance (Сопротивление 4 провода)

**Диапазоны:**
- `200 Ω` — 200 ом
- `2 kΩ` — 2 килоома
- `20 kΩ` — 20 килоом
- `200 kΩ` — 200 килоом
- `2 MΩ` — 2 мегаома
- `10 MΩ` — 10 мегаом
- `100 MΩ` — 100 мегаом
- `AUTO` — автоматический выбор диапазона

**Единица измерения:** Ω (омы)

### Frequency (Частота)

**Диапазоны:**
- `AUTO` — автоматический выбор диапазона

**Единица измерения:** Hz (герцы)

> ⚠️ **Примечание**: Для измерения частоты используется автоматический выбор диапазона.

### Capacitance (Емкость)

**Диапазоны:**
- `2 nF` — 2 нанофарад
- `20 nF` — 20 нанофарад
- `200 nF` — 200 нанофарад
- `2 uF` — 2 микрофарад
- `20 uF` — 20 микрофарад
- `10000 uF` — 10000 микрофарад (вместо 10 mF)
- `AUTO` — автоматический выбор диапазона

**Единица измерения:** F (фарады)

> ⚠️ **Примечание**: Диапазон 10 mF не поддерживается SDM4055A. Используйте 10000 uF.

### Continuity (Проверка целостности цепи)

**Диапазон:**
- `AUTO` — автоматический выбор диапазона

**Единица измерения:** Ω (омы)

**Результат:**
- Значение сопротивления или **OPEN** (разрыв цепи)

### Diode (Проверка диода)

**Диапазон:**
- `AUTO` — автоматический выбор диапазона

**Единица измерения:** V (вольты)

**Результат:**
- Напряжение на диоде или **OPEN** (разрыв цепи)

## Поиск и устранение неисправностей

### Проблема: Не удается подключиться к мультиметру

**Возможные причины:**

1. **Не установлен NI-VISA**
   - **Решение**: Установите NI-VISA с официального сайта National Instruments

2. **Мультиметр не подключен**
   - **Решение**: Проверьте подключение USB-кабеля

3. **Мультиметр занят другим приложением**
   - **Решение**: Закройте другие приложения, использующие мультиметр

4. **Неверный драйвер**
   - **Решение**: Переустановите драйвер USB-устройства

### Проблема: Устройство не обнаруживается

**Возможные причины:**

1. **Мультиметр выключен**
   - **Решение**: Включите мультиметр

2. **USB-кабель неисправен**
   - **Решение**: Замените USB-кабель

3. **NI-VISA не установлен**
   - **Решение**: Установите NI-VISA и перезагрузите компьютер

### Проблема: Ошибка при сканировании

**Возможные причины:**

1. **Неверный диапазон измерения**
   - **Решение**: Выберите подходящий диапазон или используйте AUTO

2. **Превышен предел измерения**
   - **Решение**: Используйте больший диапазон

3. **Обрыв измерительных проводов**
   - **Решение**: Проверьте подключение измерительных проводов

4. **Устройство отключено во время сканирования**
   - **Решение**: Проверьте подключение USB и подключитесь заново

### Проблема: Некорректные значения измерений

**Возможные причины:**

1. **Неверный тип измерения**
   - **Решение**: Выберите правильный тип измерения

2. **Влияние наводок**
   - **Решение**: Используйте экранированные провода для измерения малых сигналов

3. **Неверный диапазон**
   - **Решение**: Выберите более подходящий диапазон

### Проблема: Не удается создать/обновить CSV-файл

**Возможные причины:**

1. **Файл открыт в другом приложении**
   - **Решение**: Закройте файл в Excel или другом приложении

2. **Нет прав на запись**
   - **Решение**: Выберите другую папку или запустите приложение от имени администратора

3. **Неверный путь к файлу**
   - **Решение**: Проверьте правильность пути к файлу

### Проблема: Не удается экспортировать в Excel

**Возможные причины:**

1. **Не установлен Excel**
   - **Решение**: Установите Microsoft Excel или используйте альтернативные приложения для работы с CSV-файлами

2. **Файл открыт в другом приложении**
   - **Решение**: Закройте файл в Excel или другом приложении

3. **Большие размеры файла**
   - **Решение**: Разделите файл на несколько частей или используйте фильтрацию данных

### Проблема: Неверный формат серийного номера

**Возможные причины:**

1. **Серийный номер не соответствует формату**
   - **Решение**: Используйте формат PSN followed by exactly 9 digits (например, PSN123456789)

2. **Серийный номер уже существует в отчете**
   - **Решение**: Это нормально - существующая запись будет обновлена новыми данными
