# Краткая инструкция SDM4055A-SC Multimeter Controller

## Версия для EXE-файла

## Системные требования

- Windows 10 или выше
- USB-порт для подключения мультиметра
- Установленный драйвер **NI-VISA** (обязательно!)

## Установка драйвера NI-VISA

1. Скачайте NI-VISA с сайта National Instruments: https://www.ni.com/ru/support/downloads/drivers/download.ni-visa.html
2. Установите драйвер, запустив скачанный установщик
3. Подключите мультиметр SDM4055A к компьютеру по USB
4. Проверьте, что устройство определяется в системе:
   - Откройте "Диспетчер устройств"
   - Найдите раздел "NI-VISA" или "USB Test and Measurement Devices"

## Запуск программы

1. Запустите файл `SDM4055A_Controller.exe`
2. Программа автоматически определит подключённый мультиметр

## Интерфейс программы

### Основные элементы

- **16 каналов измерения** (CH1-CH16):
  - Каналы 1-12: напряжение, сопротивление, ёмкость
  - Каналы 13-16: ток (макс. 2А)
- **Кнопки управления**:
  - `Load Config` — загрузить конфигурацию каналов
  - `Create Report` — создать отчёт CSV
  - `Export to Excel` — экспорт в Excel с форматированием
  - `Single Scan` — однократное измерение
  - `Start Scan` — непрерывное сканирование
  - `Stop Scan` — остановить сканирование

### Состояния каналов

- **Цветной канал** — настроен (есть в конфигурационном файле)
- **Серый канал** — не настроен (нет в конфигурационном файле)

> **Важно**: Только настроенные каналы включаются в отчёты!

## Конфигурационный файл

### Формат CSV-файла

```csv
channel,Name,measurement_type,range,lower_threshold,upper_threshold
1,+3.3VD,VOLT:DC,AUTO,0,5
2,+5/0VA,VOLT:DC,200 mV,0,0.2
3,Test Point 3,VOLT:AC,AUTO,0,120
4,,RES,AUTO,0,1000
```

### Поля конфигурации

| Поле | Описание | Обязательно |
|------|----------|-------------|
| `channel` | Номер канала (1-16) | Да |
| `Name` | Кастомное имя канала | Нет |
| `measurement_type` | Тип измерения | Да |
| `range` | Диапазон (AUTO или значение) | Да |
| `lower_threshold` | Нижний порог | Нет |
| `upper_threshold` | Верхний порог | Нет |

### Типы измерений

Для каналов **1-12**:
- `VOLT:DC` — постоянное напряжение
- `VOLT:AC` — переменное напряжение
- `RES` — сопротивление (2-проводное)
- `FRES` — сопротивление (4-проводное)
- `CAP` — ёмкость
- `FREQ` — частота
- `DIOD` — диод
- `CONT` — прозвонка
- `TEMP:RTD` — температура RTD
- `TEMP:THER` — термопара

Для каналов **13-16**:
- `CURR:DC` — постоянный ток
- `CURR:AC` — переменный ток

### Диапазоны измерений

**Напряжение (VOLT:DC, VOLT:AC)**:
- `200 mV`, `2 V`, `20 V`, `200 V`, `AUTO`

**Сопротивление (RES, FRES)**:
- `200 Ohm`, `2 kOhm`, `20 kOhm`, `200 kOhm`, `2 MOhm`, `10 MOhm`, `100 MOhm`, `AUTO`

**Ёмкость (CAP)**:
- `2 nF`, `20 nF`, `200 nF`, `2 uF`, `20 uF`, `10000 uF`, `AUTO`

**Ток (CURR:DC, CURR:AC)** — только `2 A`!

### Пороги

- Пороги используются для визуальной индикации
- **Зелёный цвет** — значение в пределах порогов
- **Красный цвет** — значение вне порогов
- Оставьте пустым, если не нужны

## Создание конфигурации

### Вариант 1: Создать вручную

1. Откройте Блокнот
2. Скопируйте пример конфигурации
3. Сохраните как `.csv` файл с кодировкой UTF-8

### Вариант 2: Использовать пример

1. Откройте папку `examples` в каталоге программы
2. Скопируйте файл `Boreas_2v1.csv`
3. Измените под свои нужды

## Рабочий процесс

### 1. Подготовка

1. Подключите мультиметр к компьютеру по USB
2. Запустите программу
3. Убедитесь, что устройство подключено (статус "Connected")

### 2. Настройка каналов

1. Подготовьте CSV-файл с конфигурацией
2. Нажмите кнопку `Load Config`
3. Выберите ваш CSV-файл
4. Настроенные каналы станут цветными, остальные — серыми

### 3. Проведение измерений

**Однократное измерение**:
- Нажмите `Single Scan`
- Значения обновятся один раз

**Непрерывное сканирование**:
- Нажмите `Start Scan`
- Значения будут обновляться автоматически
- Нажмите `Stop Scan` для остановки

### 4. Создание отчёта

**CSV-отчёт**:
1. Нажмите `Create Report`
2. Введите QR-код изделия
3. Введите результат теста (PASS/FAIL)
4. Файл сохранится в папке с отчётами

**Excel-отчёт**:
1. Сначала создайте CSV-отчёт
2. Нажмите `Export to Excel`
3. Выберите CSV-файл
4. Excel-файл создастся с условным форматированием по порогам

## Просмотр логов

Для просмотра подробной информации о работе программы:

1. Нажмите кнопку `Logs` в главном окне
2. Откроется окно с логами
3. Можно фильтровать по уровню (DEBUG, INFO, WARNING, ERROR)
4. Кнопка `Clear Logs` очищает логи

## Решение проблем

### Устройство не определяется

1. Проверьте, что установлен NI-VISA
2. Перезагрузите компьютер после установки драйвера
3. Попробуйте другой USB-кабель
4. Проверьте Диспетчер устройств

### Ошибка при загрузке конфигурации

1. Проверьте формат CSV-файла
2. Убедитесь, что кодировка UTF-8
3. Проверьте правильность типов измерений и диапазонов
4. Смотрите подробную ошибку в окне логов

### Нет данных при сканировании

1. Убедитесь, что мультиметр подключён
2. Проверьте, что загружена конфигурация каналов
3. Проверьте подключение измерительных проводов

### Excel не открывается

1. Убедитесь, что установлен Microsoft Excel
2. Проверьте, что CSV-файл не открыт в другой программе

## Горячие клавиши

- `Ctrl+L` — загрузить конфигурацию
- `Ctrl+R` — создать отчёт
- `Ctrl+E` — экспорт в Excel
- `Space` — однократное сканирование
- `Ctrl+S` — начать сканирование
- `Ctrl+X` — остановить сканирование

## Дополнительная информация

- Поддерживается только **USB-подключение** (LAN не поддерживается!)
- Максимальное количество каналов: 16
- Формат отчётов: CSV и Excel (.xlsx)
- Автоматическое условное форматирование в Excel по порогам
